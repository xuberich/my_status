Title:
`[Open Source] EgoGaze - Self-hosted Android phone status dashboard (Docker + Cloudflare)`

Body:
Hi all, I built and open-sourced a project called **EgoGaze**.

What it does:
- Mirrors Android phone status to a web dashboard in real time
- Shows battery, location, step count, app usage duration, and music playback
- Supports self-hosted deployment with Docker
- Also supports Cloudflare Workers/KV for users without public IP

Why I made it:
- I wanted a lightweight personal status mirror with full data control

Repo: https://github.com/AVIDS2/my_status  
Live demo: https://status.dwill.top

Feedback and suggestions are welcome.
